# livery

我给自己的车设计涂装（拉花）的地方：设计稿，加上一个在浏览器里实时预览它的 3D 工坊。

这是个人项目，不是通用的涂装工具。代码按 MIT 开源，欢迎参考。

## 现状

工坊刚搭起来：能跑通渲染，画面是一块带天空环境反射的金属立方体，可以拖动旋转。车模和涂装还没有放进去。

接下来的方向：

- 放入一辆占位的双门跑车车模，车模可替换
- 涂装画在左、右、顶、前、后五张 2D 画板上，按对应方向投影到车身，改画板，3D 预览实时跟着变
- 画板按真实尺寸绘制，可以直接作为贴膜店的施工稿

## 运行

需要 Node 22 以上、pnpm，以及支持 WebGPU 的浏览器（新版 Chrome、Edge、Safari、Firefox 都可以）。

```sh
pnpm install
pnpm dev
```

然后打开终端里显示的本地地址。

## 结构

- `wiki/`：设计思路、调研和计划
